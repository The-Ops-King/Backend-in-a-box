Run page, five structures

One person's run of the pre-call sequence. Every structure has the same five parts: the header (who, which workflow, where it stands), the steps (the same rows as the sheet on the runs list), the messages (what went out and what came back, the words), what happens next, and the chart with this run's path lit. On a phone the chart shows only the path this run took; on a laptop the whole chart with the path lit.
